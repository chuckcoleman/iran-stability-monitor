Timestamp policy

Evidence collection closes before probability elicitation. Every update records the actual evidence cutoff and publication time. Information first available after the cutoff is excluded from that forecast.

Judgmental uncertainty

Set the point forecast first. Then estimate the 10th and 90th percentiles of the point probabilities that independent, well-informed analysts using the same information, definition and horizon would give. This is a reasonable-analyst interval, not a statistical confidence or credible interval.
